# Random String

Random String

## Usage

``` r
rstring(n = 30)
```

## Arguments

- n:

  an integer, the length of the string.

## Value

a character string.

## Details

The function produces character strings based on sampling alphanumerical
characters.

## Examples

``` r
rstring()
#> [1] "SwlKLUUEdLieexomb92Q9QeuR8HfdV"
rstring(n = 10)
#> [1] "HIyvQgF0fi"
```
